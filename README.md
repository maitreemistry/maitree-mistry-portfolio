## Tech Stack

- Next.js 15 with the App Router
- React and TypeScript
- Tailwind CSS
- Lucide React icons
- Radix UI primitives
- Genkit flows for the project's AI functionality

## Getting Started

### Prerequisites

- Node.js 18 or later
- npm

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

The site is available at http://localhost:9002.

### Build for production

```bash
npm run build
npm start
```

## Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Next.js development server on port 9002 |
| `npm run build` | Create an optimized production build |
| `npm start` | Serve the production build |
| `npm run typecheck` | Run the TypeScript compiler without emitting files |
| `npm run genkit:dev` | Start the Genkit development environment |
| `npm run genkit:watch` | Start Genkit with file watching enabled |

## Project Structure

```text
src/
	app/          Next.js routes, metadata, and global styles
	components/   Portfolio sections and shared UI components
	ai/           Genkit configuration and flows
	hooks/        Reusable React hooks
	lib/          Shared utilities
public/         Images and other static assets
```
